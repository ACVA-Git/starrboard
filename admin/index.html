Configuration Walkthrough

Follow these cards in order after the apps are installed and reachable.

1. Media folders

  1. If you already have a Plex library, point Starrboard/Radarr to the existing Movies root and Starrboard/Sonarr to the existing TV Shows root.
  2. If this is a new Plex library, create one movie root and one TV root that the Arr services can access.
  3. Use a real local path or UNC share path, not a mapped drive letter for Windows services.
  4. Enter only the root: D:\Plex\Movies or \\nas\media\Movies. Radarr creates Movie Name (Year) folders under it.
  5. Enter only the root: D:\Plex\TV Shows or \\nas\media\TV Shows. Sonarr creates show and season folders under it.
  6. Plex-friendly final layout is Movies\Movie Name (Year)\Movie Name (Year).ext and TV Shows\Show Name (Year)\Season 01\Show Name - S01E01.ext.

2. Radarr and Sonarr API keys

  1. Open Radarr or Sonarr from Stack Consoles.
  2. Go to Settings > General.
  3. Copy the API Key into Starrboard Configuration.
  4. Save the URL and API key in Starrboard, then select one of the quality profiles loaded directly from the service.
  5. Profile numbers are internal database IDs, not quality rankings. Starrboard hides them because a larger number does not mean better quality.
  6. To create or change a profile, use Settings > Profiles in Radarr or Sonarr, save it there, then reload Starrboard.

3. qBittorrent Web UI

  1. Open qBittorrent locally.
  2. Go to Tools > Options > Web UI.
  3. Enable Web User Interface and set the port, usually 8080.
  4. Set a username and password if desired, then save.
  5. In Radarr and Sonarr, add qBittorrent under Settings > Download Clients.

4. Prowlarr indexers and apps

  1. Open Prowlarr and go to Settings > General to copy its API key.
  2. Add indexers under Indexers > Add Indexer.
  3. Add Radarr and Sonarr under Settings > Apps.
  4. Use each app's URL and API key so Prowlarr can sync indexers to them.
  5. Test each app connection before validating Starrboard.

5. FlareSolverr for protected indexers

  1. Start FlareSolverr and confirm http://127.0.0.1:8191 opens.
  2. In Prowlarr, go to Settings > Indexers.
  3. Add an indexer proxy and choose FlareSolverr.
  4. Use host http://127.0.0.1:8191.
  5. Only tag indexers that need Cloudflare/DDOS challenge solving; do not route every indexer through it unless required.

6. Windows service account

  1. If media is on a NAS or protected folder, create or choose a dedicated service account that has SMB share and file permissions.
  2. Do not use the built-in Administrator account unless this is only a temporary test.
  3. Choose the target services in Configuration, then open Configure Service Account. Starrboard securely prompts for the username and password, validates them, and applies the account without saving the password.

7. Starrboard final validation

  1. Open Configuration and save Discord, Arr, qBittorrent, FlareSolverr, and folder settings.
  2. Open Onboarding and click Validate Stack.
  3. Fix any missing or attention cards.
  4. Click Mark Setup Complete only when all required cards are ready.
  5. Test a private Discord request and confirm Radarr/Sonarr starts a search.
